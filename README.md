# Vesper Launcher (Go Monorepo) 🚀

> Официальный единый репозиторий **Vesper Launcher**, полностью переведённый на **Golang** (Wails v2 + React 18 / Vite) со встроенной системой обновлений и архивом исторической кодовой базы.

## 🏗 Архитектура единого репозитория

```
├── cmd/
│   ├── vesper-update-server/      # Высокопроизводительный сервер раздачи обновлений и манифестов
│   ├── vesper-updater-cli/        # Автономная CLI-утилита проверки и скачивания обновлений
│   └── vesper-release-publisher/  # Инструмент сборки релизных манифестов (SHA256, размеры файлов)
├── pkg/
│   └── updater/                   # Кроссплатформенная библиотека обновлений (SemVer, SHA256, атомарная замена)
├── internal/                      # Подсистемы лаунчера (Wails Bridge, Minecraft, моды, авторизация, скины, Java)
│   ├── bridge/                    # Мост между Go и React UI
│   ├── minecraft/                 # Загрузка, аргументы, инсталляция Fabric/Forge/NeoForge/OptiFine, фикс 1.16.5
│   ├── mods/                      # Интеграция с каталогами Modrinth и CurseForge
│   ├── java/                      # Автодетекция и валидация сред исполнения Java (8, 16, 17, 21)
│   ├── account/                   # Аккаунты Vesper, Microsoft OAuth, Ely.by
│   ├── updater/                   # Интеграция механизма обновлений в лаунчер
│   └── verification/              # Полная верификационная матрица тестов (70 пунктов)
├── frontend/                      # Интерфейс на React 18 + TypeScript + Vite + Liquid Glass
├── manifest.json                  # Корневой манифест актуальной версии и зеркал
├── csharp-legacy-source.zip       # Архив старой кодовой базы на C#
├── main.go / app.go               # Точки входа Wails-приложения
├── build.sh                       # Скрипт полной сборки
└── .github/workflows/             # GitHub Actions CI/CD
```

## ⚡ Особенности реализации

* **Сверхбыстрый запуск и минимальное потребление RAM**: благодаря замене тяжелого .NET рантайма на скомпилированный бинарный код Go + WebKitGTK.
* **Встроенная система обновлений (`Updates System`)**:
  * **Клиент и CLI**: проверка по `manifest.json`, загрузка с валидацией хеша SHA256, атомарная замена бинарника (`ApplyBinaryUpdate`).
  * **Сервер обновлений**: выдача манифестов, проверка версий (`/api/v1/updates/check`), новостная лента.
  * **Генератор релизов**: автоматический подсчёт контрольных сумм и сборка манифеста.
* **Поддержка модов и загрузчиков**: полная совместимость с Vanilla, Fabric, Forge, NeoForge, OptiFine.
* **Фикс онлайна для 1.16.5**: TLauncher-совместимый обход лицензии для игры по сети на серверах без проверки сессии Mojang.
* **Управление версиями**: быстрое удаление скачанных версий (красная корзина) и динамические состояния кнопок.
* **Бесшовный интерфейс**: исправлены белые углы на Linux (X11 / Wayland), сохранена типографика `Segoe UI` и фирменный эффект Liquid Glass.

## 🚀 Быстрый запуск и сборка

### Сборка всего лаунчера
```bash
# Сборка фронтенда и лаунчера:
./build.sh

# Запуск лаунчера:
./build/bin/VesperLauncher
```

### Запуск системы обновлений

```bash
# Запуск локального сервера обновлений:
go run ./cmd/vesper-update-server -port 8080 -manifest manifest.json

# Проверка обновлений через CLI:
go run ./cmd/vesper-updater-cli --check --version 1.0.65

# Сборка нового манифеста для релиза:
go run ./cmd/vesper-release-publisher --version 1.0.66 --dir ./dist --out manifest.json
```

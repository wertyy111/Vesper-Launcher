# Vesper Launcher (Go Port)

Vesper Launcher, полностью портированный с C# (.NET 10 / Photino) на Golang (Wails v2 + WebKitGTK-4.1) и React 18 + Vite.

* Подробное описание архитектуры и дерева каталогов: см. [STRUCTURE.md](STRUCTURE.md).

## Быстрый запуск

```bash
# Сборка фронтенда и Go бинарника:
./build.sh

# Запуск лаунчера:
./build/bin/VesperLauncher
```
